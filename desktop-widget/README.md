# TimeKeeper 캘린더 바탕화면 위젯

TimeKeeper 캘린더(일정 · 공휴일 · 근태)를 바탕화면에 반투명 창으로 띄운다. Electron 앱이다.

## 데이터가 오는 길

위젯은 브라우저와 저장소가 달라서 TimeKeeper 데이터를 직접 읽지 못한다.
TimeKeeper 앱이 캘린더 값이 바뀔 때마다 **자동 백업 폴더**에 `timekeeper-calendar-widget.json` 을 쓰고, 위젯은 그 파일을 지켜보다 다시 그린다.

1. TimeKeeper 설정 › 데이터 관리에서 「자동 백업 폴더」를 고르고 권한을 「방문할 때마다 허용」으로 둔다.
2. TimeKeeper 를 한 번 연다. 폴더에 `timekeeper-calendar-widget.json` 이 생긴다.
3. 위젯을 처음 켜면 폴더를 묻는다. 같은 폴더를 고른다.

TimeKeeper 탭이 열려 있고 폴더 권한이 살아 있을 때만 파일이 갱신된다. 위젯 아래쪽 「갱신 시각」으로 확인한다.

## 쓰는 법

- 머리(제목 줄)를 끌어 옮기고, 가장자리를 끌어 크기를 바꾼다. 위치·크기는 기억한다.
- 머리의 ◐ 슬라이더 또는 트레이 메뉴 「배경 진하기」로 배경 투명도를 바꾼다. 글자는 그대로다.
- 트레이 아이콘 메뉴: 클릭 통과(잠금) · 항상 위 · 윈도우 시작 시 실행 · 폴더 바꾸기 · TimeKeeper 열기 · 종료.
  트레이 아이콘을 누르면 위젯을 숨기거나 다시 보인다.

## 개발 · 빌드

```bash
npm install
npm start         # 개발 실행
npm run dist      # dist/ 에 포터블 exe
```

화면만 브라우저에서 보려면 저장소 루트에서 `npx vite desktop-widget/renderer` (예시 데이터로 그린다).

## 한계

- 윈도우에는 「바탕화면에 붙이기(항상 아래)」 API 가 없어 보통 창처럼 겹친다. Win+D(바탕화면 보기)를 누르면 같이 숨는다.
- 위젯은 보기 전용이다. 일정 추가·수정은 TimeKeeper 에서 한다.
