v.1.0.12 - 간트차트에서 시간을 고치고, 시계로 시간을 고를 수 있습니다!

간트차트 막대를 섬세하게 맞출 수 있고, 업무 기록 수정 창에서 시간도 바꿀 수 있습니다.
시간 입력을 시계 위젯으로 바꿀 수 있고, 할로윈 테마가 추가되었습니다.


📊 1. 간트차트
1) 끄는 속도에 따라 붙는 정도가 달라집니다
- 천천히 맞추면 놓은 자리 그대로 들어갑니다 (옆 세션 경계에 2분 안일 때만 붙음)
- 휙 끌어서 놓으면 예전처럼 근처 경계에 붙습니다 (세션 경계 15분, 09:00 · 18:00 · 점심 5분 안)
   예) 빠르게 09:02 에 놓으면 ➡️ 09:00 / 천천히 09:02 에 놓으면 ➡️ 09:02
- 놓기 전 0.5초 안의 가장 빠른 속도로 판단합니다. 빠르게 끌다 놓기 직전에 멈칫해도 빠르게 놓은 것으로 봅니다
- 막대 양끝 늘이기 · 줄이기, 빈 곳을 끌어 새 세션 만들기 모두 같습니다

2) 업무 기록 수정에서 시간을 바꿀 수 있습니다
👉 [여는 방법] 간트차트 막대 우클릭 ➡️ "수정"
- 업무 제목 아래 [시작 – 종료] 칸에서 시간을 고치면 오른쪽에 소요 시간이 바로 나옵니다
- 종료가 시작보다 이르면 빨간 안내가 나오고 저장되지 않습니다
- 진행 중인 기록은 종료 칸이 「진행 중」으로 잠기고 시작만 고칠 수 있습니다
- 다른 기록과 겹치면 막대를 끌 때처럼 자동으로 조정되고 알림이 뜹니다

(※ 06시 전 시간(예: 01:00)은 다음 날 새벽으로 처리됩니다. 간트차트의 하루는 06:00 ~ 다음 날 06:00 입니다.)


🕘 2. 시간 입력 방식 (시계 위젯)
👉 [설정] 톱니바퀴(⚙️) ➡️ [시간 입력 방식] 섹션 ➡️ [기본 입력 | 시계 위젯]
   옆의 미리보기 칸을 눌러 바로 써 볼 수 있습니다

- 적용되는 곳: 간트차트 업무 기록 수정 · 최근 업무 기록 작업 이력 · 새 업무 예약 시간
- 시간 칸을 누르면 위에 [시 : 분], 아래에 시계판이 뜹니다 (24시간, 안쪽 원이 13~24시)
- 숫자로 바로 입력: 열리자마자 시 칸에 커서가 있어 클릭 없이 숫자를 치면 됩니다
   시 두 자리를 치면 분으로 넘어갑니다. 예) 1 4 3 5 ➡️ 14:35
   시간 칸에 포커스만 둔 상태에서 숫자를 쳐도 열리면서 입력됩니다
- 시계판: 시를 고르면 분 화면으로 넘어가고, 분까지 고르고 손을 떼면 바로 확정됩니다
- Tab: 시 ➡️ 분 ➡️ 확정하고 다음 칸으로. 다음 칸이 시간 칸이면 그 위젯이 바로 열립니다
   예) 업무 기록 수정에서 0 9 3 0 Tab 1 2 0 5 ➡️ 시작 09:30 · 종료 12:05 (Shift+Tab 은 반대로)
- 확정: 확인 · Enter · Tab · 위젯 바깥 클릭 / 취소: 취소 버튼 · Esc
- 작업 이력 칸에서는 확정하면 바로 저장됩니다

(※ 최근 업무 기록 연필(✏️) 수정 창은 날짜까지 함께 고르는 칸이라 기본 입력 그대로입니다.)


📝 3. 최근 업무 기록
- 손잡이(⠿)를 끌어 업무 순서를 바꿀 수 있습니다. 바꾼 순서는 저장됩니다
   진행 중인 업무는 항상 맨 위, 새로 생긴 업무는 그 다음에 기본 정렬로 들어갑니다
   [기본 정렬로] 버튼을 누르면 끌어서 바꾼 순서를 지웁니다
- 작업 이력 표: 비고 칸이 넓어지고 시작 · 종료 시간 칸이 좁아졌습니다. 날짜는 한 줄로 나옵니다


✏️ 4. 입력 칸
- 무엇을 하고 계신가요? 의 비고 칸이 글자에 맞춰 늘어납니다 (최대 360px)
- 진행 중 카드의 비고 수정 칸도 글자에 맞춰 업무명 끝까지 늘어납니다
- 작업 프리셋 추가 · 수정 창의 프로젝트 코드 · 프로젝트명이 업무 기록 수정 창과 같은 두 칸으로 바뀌었습니다
   (코드와 이름을 모두 넣고 저장하면 새 프로젝트로 등록됩니다)


↔️ 5. 작업 프리셋 폭 조절
- 작업 프리셋 패널 오른쪽 아래 모서리를 끌어 폭을 줄이면, 오른쪽 영역(간트차트 · 입력줄 · 최근 업무 기록)이 그만큼 넓어집니다
- 200 ~ 450px 사이로 조절됩니다

(※ 조절한 폭은 새로고침하면 기본 280px 로 돌아갑니다.)


🎃 6. 할로윈 테마
👉 [설정] 톱니바퀴(⚙️) ➡️ [테마 및 컬러 팔레트] ➡️ "할로윈"
- 보라 · 주황 팔레트에 유령과 박쥐가 화면을 떠다닙니다
- 휴지통은 무덤(🪦)이 되고, 간트차트 점심시간 칸엔 박쥐가 매달려 있습니다
- 이스터에그가 잔뜩 숨어 있습니다 👻 (기록 데이터는 절대 건드리지 않습니다)
   · 버튼이 아닌 빈 곳을 빠르게 5번 누르면…
   · 유령에 마우스를 가져다 대면… (마우스를 좌우로 마구 흔들면 풀려납니다 · Esc 로도 풀림)
   · 다크모드 버튼을 정신없이 누르면…
   · 마우스를 한참 가만히 두면… 누가 보고 있는 것 같기도
   · 밤늦게까지 타이머를 돌리면…
   · 업무를 지우거나, 끝내면…
   · 업무명에 "유령"이나 "호박"을 넣어 보세요
   · 타이머가 불길한 숫자에 닿으면…
   · ↑↑↓↓←→←→BA
   · 10월 31일에 열어 보세요 🎃
   · 메뉴 이름이 좀 이상하지 않나요? 그리고 가만히 있어도 가끔 화면이…

(※ 움직임 줄이기 설정을 켠 기기에서는 깜빡임 · 화면 회전 · 메뉴 글리치가 꺼지고, 터치 기기에서는 유령이 마우스를 잡지 않습니다.)
