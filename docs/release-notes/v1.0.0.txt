v.1.0.0 - 카테고리가 ERP와 같아지고, 시간관리가 더 편해졌습니다!

이번 업데이트에서는 카테고리 목록을 ERP와 똑같이 맞추고, 시간관리 표에 종료예정일·다중 정렬을 더했습니다.
쌓인 기록을 정리해 백업 파일 용량을 줄이는 기능과 여러 버그 수정도 함께 담겼습니다.


🗂️ 1. 카테고리를 ERP 목록과 맞췄습니다
카테고리 코드표를 ERP "일정관리-카테고리조회" 목록과 똑같이 바꿨습니다.
기존 "탐색업무"(07)는 ERP 이름인 "팀장업무"로 바뀌며, 이미 기록된 업무와 시간관리 표도 함께 바뀝니다.
ERP 목록에 없는 카테고리가 있으면 [시간관리 등록] 화면에서 저장 전에 알려줍니다.

👉 [꼭 해주세요] 카테고리 오류를 없애려면 카테고리 목록을 한 번 초기화해 주세요.
   ➡️ 우측 상단의 톱니바퀴(⚙️) 아이콘을 눌러 설정 화면으로 이동
   ➡️ [카테고리 관리] 섹션 확인
   ➡️ [기본값으로 초기화] 클릭

(※ 직접 추가해 둔 카테고리는 초기화하면 사라집니다. 필요한 카테고리는 초기화 후 다시 추가해 주세요.)


📅 2. 시간관리 종료예정일 컬럼 추가
시간관리 표에 [종료예정일] 컬럼이 추가되었습니다. 기본값은 오늘 날짜이며, 셀을 클릭해 날짜를 바꿀 수 있습니다.
ERP에 등록할 때 이 날짜가 종료 예정일로 들어가고, 엑셀 Export에도 포함됩니다.


↕️ 3. 시간관리 다중 정렬
헤더를 차례로 누르면 이전 정렬을 유지한 채 새 기준이 더해집니다.
먼저 누른 컬럼이 1순위이고, 나중에 누른 컬럼은 앞 기준이 같은 행끼리 정렬합니다. (헤더 옆 숫자가 순위)
같은 헤더를 다시 누르면 오름차순/내림차순이 바뀌고, 한 번 더 누르면 그 기준만 해제됩니다.


🧹 4. 오래된 기록 정리
설정 > 데이터 관리에 [오래된 기록 정리]가 추가되었습니다. 날짜를 고르면 그 이전의 타이머 기록·휴지통·시간관리 행을 지워 백업 파일 용량을 줄입니다.
👉 날짜 선택 ➡️ [먼저 백업] ➡️ 삭제 대상 건수 확인 ➡️ [삭제]
(※ 되돌릴 수 없으니 꼭 백업 후 진행해 주세요. 프리셋·설정·배포 캘린더는 그대로 남습니다.)


🐞 5. 버그 수정
- 예약 모드에서 시간(오후 07:00)이 잘려 보이던 문제
- 배포 캘린더에서 이벤트 추가 창을 다시 열면 이전에 입력한 진행상태·프로젝트 값이 남아 있던 문제
- 배포 캘린더에서 프로젝트 코드를 바꿔도 표시명이 이전 프로젝트 이름으로 남던 문제
- 진행 중 업무·업무 기록 수정 창에서 카테고리 목록이 잘리거나 스크롤되지 않던 문제
- 진행 중 업무에서 [프로젝트 추가]로 직접 입력한 프로젝트가 반영되지 않던 문제
- 업무 입력 시 프로젝트명을 지우면 프로젝트 코드까지 지워지던 문제
