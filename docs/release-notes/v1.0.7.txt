v.1.0.7 - ERP 시간관리 등록 오류 수정 + 첫 화면이 빨라졌습니다

세션키에 기호(!)가 들어간 경우 ERP 저장이 계속 실패하던 문제를 고쳤습니다.
함께 첫 로딩에 받는 파일을 절반 이하로 줄였습니다.


🔧 1. ERP 시간관리 등록 - 세션 오류 수정
세션키(ec_req_sid)에 ! 같은 기호가 들어 있으면 키가 중간에서 잘려,
로그인이 멀쩡한데도 "세션 만료 또는 잘못된 세션키입니다" 오류가 났습니다.

- 주소 전체를 붙여넣어도 세션키를 끝까지 읽습니다
- 세션키만 붙여넣어도 인식합니다
- 입력칸 아래에 읽어들인 세션키 전체가 보입니다. ERP 탭 주소의 ec_req_sid 와 눈으로 대조할 수 있습니다

(※ 그래도 오류가 나면 ERP에 다시 로그인한 뒤 그 탭의 주소를 다시 복사해 주세요. 세션키는 로그인할 때마다 새로 발급됩니다.)


⚡ 2. 첫 화면 로딩 속도 개선
처음 접속할 때 받던 파일이 1.2MB 에서 549KB 로 줄었습니다.

- 엑셀 내보내기에 쓰는 기능(약 400KB)은 [엑셀 Export] 를 누를 때만 받습니다
- 주간 일정 / 배포 캘린더 / 프로젝트 분석 / 시간관리 / 설정 / 가이드 화면은 그 탭을 처음 열 때 받습니다
- 탭을 여는 순간 잠깐 동그란 표시가 돌 수 있습니다. 한 번 받으면 다시 받지 않습니다


📂 3. 카테고리 관리 - ERP 목록에서 고르기
[설정] > [카테고리 관리] 의 입력칸을 누르면 ERP에 등록된 카테고리 목록이 뜹니다.

- 목록에서 고르면 ERP와 이름이 정확히 같은 카테고리가 추가됩니다 (등록 오류 예방)
- 이미 추가한 카테고리는 목록에서 빠집니다
- 예전처럼 직접 입력해서 추가하는 것도 그대로 됩니다
