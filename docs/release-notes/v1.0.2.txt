v.1.0.2 - 지금 바로 시작하지 않을 업무를 할 일로 적어둘 수 있습니다!

이번 업데이트에서는 해야 할 업무를 타이머를 켜지 않고 [최근 업무 기록]에 미완료 상태로 먼저 등록하는 [할 일로 추가] 기능이 추가되었습니다.
생각난 업무를 잊지 않게 적어두고, 시작할 때 ▶ 버튼 하나로 바로 타이머를 켤 수 있습니다.


📝 1. 할 일로 추가
일간 타이머 입력창 오른쪽 버튼이 [예약 모드] → [할 일로 추가] → [타이머 시작] 순서로 바뀌었습니다.

👉 [사용 방법] 입력창에 작업명 입력 (프로젝트·카테고리·비고도 함께 입력 가능)
   ➡️ [할 일로 추가] 아이콘 클릭 또는 Ctrl + Enter
   ➡️ [최근 업무 기록]에 완료되지 않은(체크 해제) 0분 업무로 추가됨 (타이머는 시작되지 않습니다)
   ➡️ 시작할 때는 해당 업무의 ▶ 버튼 클릭

(※ 시작하지 않은 할 일은 간트차트·주간 일정·시간관리 집계에는 나타나지 않습니다.)
(※ 필요 없어진 할 일은 휴지통 아이콘으로 삭제하거나 체크해서 완료 처리할 수 있습니다.)
(※ 예약 모드에서는 [할 일로 추가] 버튼이 보이지 않습니다.)


⌨️ 2. 입력창 단축키
작업명이나 비고 입력칸에서 아래 단축키를 쓸 수 있습니다.
- Enter : 타이머 바로 시작 (예약 모드에서는 예약 등록)
- Ctrl + Enter : 할 일로 추가
- Alt + Enter : 예약 모드 켜기 (작업명은 그대로 두고 예약 시간을 다음 정각으로 채움 → 시간 확인 후 Enter로 예약 등록)
