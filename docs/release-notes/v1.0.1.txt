v.1.0.1 - 자동 백업 파일을 원하는 폴더에 저장할 수 있습니다!

일일 자동 백업 파일이 다운로드 폴더에 쌓이지 않도록, 저장할 폴더를 직접 지정하는 기능이 추가되었습니다.


📁 1. 자동 백업 저장 폴더 지정
일일 자동 백업 파일을 다운로드 폴더가 아닌 원하는 폴더에 바로 저장할 수 있습니다.
👉 우측 상단의 톱니바퀴(⚙️) 아이콘을 눌러 설정 화면으로 이동
   ➡️ [데이터 관리] 섹션에서 "일일 자동 백업 사용" 켜기
   ➡️ [폴더 선택]을 눌러 저장할 폴더 지정

(※ 브라우저를 다시 켜면 폴더 권한 확인이 필요할 수 있습니다. [권한 다시 허용]을 누르고 "방문할 때마다 허용"을 선택하면 계속 유지됩니다.)
(※ 권한이 없거나 지원하지 않는 브라우저에서는 기존처럼 다운로드 폴더로 저장됩니다. 크롬·웨일·엣지에서 사용할 수 있습니다.)
(※ [데이터 수동 내보내기]는 기존처럼 다운로드로 저장됩니다.)
