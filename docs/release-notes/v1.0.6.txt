v.1.0.6 - 시간관리 비고에 일정명이 기본으로 들어가지 않습니다!

건의해 주신 "시간관리 등록 할 때 비고에 기본값으로 일정명 안 들어가게 할 수 있으면 좋겠습니다"를 반영했습니다.
이제 비고에는 타이머에 적은 비고만 들어갑니다. 비고를 적지 않은 업무만 작업명으로 채우고 싶다면 설정에서 켜면 됩니다.


📝 1. 비고가 없으면 작업명으로 채우기 (설정)
시간관리 표를 [일간 타이머에서 불러오기] 할 때 비고에는 타이머에 적은 비고만 들어갑니다.
같은 업무에 비고를 여러 번 적었다면 줄바꿈으로 이어 붙습니다.

👉 [설정 방법] 우측 상단의 톱니바퀴(⚙️) 아이콘을 눌러 설정 화면으로 이동
   ➡️ [업무 환경] 섹션에서 "비고가 없으면 작업명으로 채우기" 스위치 확인
   ➡️ 끄면(기본) 비고를 적지 않은 업무는 비고가 빈칸으로 남습니다

- 비고를 적은 업무: 스위치와 상관없이 그 비고가 그대로 들어갑니다
- 비고를 안 적은 업무: 끄면 빈칸, 켜면 작업명이 들어갑니다

(※ 비고는 불러올 때 채워집니다. 이미 만들어 둔 행은 [일간 타이머에서 다시 불러오기]를 눌러야 새 설정이 적용됩니다.)
(※ ERP 시간관리 등록은 시간관리 표의 비고를 그대로 보냅니다. 표에서 비고를 직접 고치면 고친 값이 그대로 들어갑니다.)
(※ 거래형(일정명) 칸은 설정과 상관없이 그대로 유지됩니다.)


📖 2. 가이드에 예시 추가
[가이드] 탭 > 시간관리 화면에 "비고가 없는 업무를 작업명으로 채우기" 움직이는 예시가 추가되었습니다.
스위치를 켜고 다시 불러왔을 때 비고가 어떻게 바뀌는지 화면으로 확인할 수 있습니다.
