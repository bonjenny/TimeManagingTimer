v.1.0.4 - 시간관리 비고에 작업명을 넣을지 직접 고를 수 있습니다!

건의해 주신 "시간관리 등록 할 때 비고에 기본값으로 일정명 안 들어가게 할 수 있으면 좋겠습니다"를 반영했습니다.
이제 비고에는 타이머에 적은 비고만 들어가고, 작업명을 함께 넣고 싶을 때만 설정에서 켜면 됩니다.


📝 1. 시간관리 비고에 작업명 포함 (설정)
👉 [설정 방법] 우측 상단의 톱니바퀴(⚙️) 아이콘을 눌러 설정 화면으로 이동
   ➡️ [업무 환경] 섹션에서 "시간관리 비고에 작업명 포함" 스위치 확인
   ➡️ 끄면(기본) 비고에 작업명이 들어가지 않습니다

- 끄기 (기본): 비고 = 타이머에 적은 비고. 비고를 안 적었으면 빈칸
- 켜기: 비고 = 작업명 // 비고. 비고를 안 적었으면 작업명만

(※ 비고는 [일간 타이머에서 불러오기] 할 때 채워집니다. 이미 만들어 둔 행은 [일간 타이머에서 다시 불러오기]를 눌러야 새 설정이 적용됩니다.)
(※ ERP 시간관리 등록은 시간관리 표의 비고를 그대로 보냅니다. 표에서 비고를 직접 고치면 고친 값이 그대로 들어갑니다.)
(※ 거래형(일정명) 칸은 설정과 상관없이 그대로 유지됩니다.)


📖 2. 가이드에 예시 추가
[가이드] 탭 > 시간관리 화면에 "비고에 작업명을 넣을지 설정에서 고르기" 움직이는 예시가 추가되었습니다.
스위치를 켜고 다시 불러왔을 때 비고가 어떻게 바뀌는지 화면으로 확인할 수 있습니다.
