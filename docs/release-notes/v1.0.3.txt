v.1.0.3 - 앱 안에서 움직이는 예시로 사용법을 확인하세요!

이번 업데이트에서는 상단에 [가이드] 탭이 추가되었습니다.
화면마다 실제 화면처럼 움직이는 예시가 반복 재생되어, 드래그·우클릭·입력 순서를 보고 그대로 따라 할 수 있습니다.


📖 1. 가이드 탭
상단 탭 맨 오른쪽 [가이드]를 누르면 왼쪽 목차에서 보고 싶은 화면을 고를 수 있습니다.
시작하기 / 일간 타이머 / 주간 일정 / 배포 캘린더 / 프로젝트 분석 / 시간관리 / ERP 시간관리 등록 / 설정 / Q&A 게시판 / 키보드 단축키

각 화면에는 아래 내용이 들어 있습니다.
   ➡️ 움직이는 예시 화면
   ➡️ 주요 기능 표 (기능 · 사용 방법 · 도입 버전)
   ➡️ 알아두세요 (주의사항과 팁)

(※ 예시 위에 마우스를 올리면 그 장면에서 멈춥니다.)
(※ 예시의 숫자와 이름은 설명용이며 내 데이터와는 관계없습니다.)


🎬 2. 이런 예시를 볼 수 있어요
- 일간 타이머: 작업 시작, 예약 모드, 타임라인 우클릭 드래그로 예약, 드래그로 지난 업무 기록, 막대 끝을 끌어 시간 조절, 막대 우클릭 수정·삭제
- 주간 일정: 복사 형식을 고르고 복사
- 배포 캘린더: 일정 칩을 드래그해 날짜 이동
- 프로젝트 분석: 카테고리 펼쳐 보기, 인터럽트 분석(키워드로 돌발 업무가 몰린 주·시간대 찾기)
- 시간관리: 머리글을 차례로 눌러 다중 정렬
- ERP 시간관리 등록: 세션 붙여넣기 → 게시글 매핑 찾기 → ERP에 저장
- 설정: 자동 백업 폴더 권한을 「방문할 때마다 허용」으로 유지, 백업 후 오래된 기록 정리
- Q&A 게시판: 건의사항 글쓰기
- 키보드 단축키: Alt + 숫자로 탭 이동


🎨 3. 상단 탭 개선
탭이 늘어나 화면 폭이 좁을 때 오른쪽 탭이 다크 모드 버튼에 가려지던 문제가 있어, 탭 줄이 좌우로 스크롤되도록 바뀌었습니다.
