v.1.0.8 - 프로젝트를 어느 화면에서든 바로 등록할 수 있습니다

지금까지 새 프로젝트는 [무엇을 하고 계신가요?] 입력줄에서만 만들 수 있었습니다.
이제 프로젝트 코드를 넣는 모든 자리에서 새 프로젝트를 만들고 지울 수 있습니다.


➕ 1. 새 프로젝트 등록 - 어디서나
목록에 없는 코드를 입력하면 드롭다운 맨 위에 [＋ 「코드」 새 프로젝트로 등록] 줄이 뜹니다.
누르면 기록에 코드가 바로 들어가고, 이름을 받는 작은 창이 뜹니다.

- 최근 업무 기록 > 프로젝트 코드 칸
- 진행 중 카드 > [프로젝트 추가]
- 업무 기록 수정 창 (최근 업무 기록의 연필, 타임라인 막대 우클릭 > 수정)

(※ 이름 창에서 [나중에] 를 눌러도 기록에는 코드가 남습니다. 프로젝트 목록에만 등록되지 않습니다.)
(※ 업무 기록 수정 창에는 프로젝트 명 칸이 따로 있습니다. 코드와 이름을 넣고 저장하면 등록됩니다.)


🎨 2. 프로젝트 드롭다운 정리
모든 프로젝트 드롭다운이 같은 모양이 되었습니다.

- 프로젝트 코드 칸: 코드가 굵은 글씨, 이름이 아래 회색 글씨
- 프로젝트 명 칸: 이름이 굵은 글씨, 코드가 아래 회색 글씨
- 코드로도 이름으로도 검색됩니다
- 항목 오른쪽 ✕ 로 프로젝트 목록에서 지울 수 있습니다 (기록은 그대로 남습니다)
- 글자가 여러 줄로 접히던 문제를 고쳤습니다
- 타이핑해도 목록이 걸러지지 않던 문제를 고쳤습니다


✏️ 3. 진행 중 카드 정리
- 프로젝트 칩에 코드 대신 프로젝트 명이 보입니다 (이름이 없으면 코드)
- 칩을 누르면 프로젝트 코드 한 칸만 뜹니다 (코드/이름 두 칸에서 하나로)
- 입력칸이 카드 끝까지 늘어나지 않고 드롭다운 폭(280px)에 맞춰집니다


🐛 4. 그 밖의 수정
- 프로젝트 코드를 지우면 프로젝트 명까지 같이 지워지던 문제 (반대 방향은 v1.0.2 에서 수정)
- [업무 기록 수정] 의 프로젝트 코드 칸에 "[코드] 이름" 이 한꺼번에 들어가던 것을 코드만 보이도록 변경
- [설정] > [진행상태 관리] 의 표시명 / 값 입력칸에 ✕ 추가
