v.1.0.10 - 새 업무 기록 (수동) - 프로젝트 코드 / 프로젝트 명 분리

ERP 저장이 "부서 미등록코드" 로 실패하던 문제와, 대괄호로 시작하는 프로젝트 이름이 코드로 잘못 저장되던 문제를 고쳤습니다.


📝 1. 새 업무 기록 (수동) - 프로젝트 코드 / 프로젝트 명 분리
타임라인 빈칸을 드래그해 여는 [새 업무 기록 (수동)] 창에 [프로젝트 명] 칸이 생겼습니다.
업무 기록 수정 창과 같은 모양입니다.

- 코드를 고르면 이름이, 이름을 고르면 코드가 채워집니다
- 목록에 없는 코드와 이름을 함께 넣고 저장하면 새 프로젝트로 등록됩니다
- 드롭다운은 코드 / 이름 두 줄로 보이고, 항목 옆 ✕ 로 프로젝트를 지울 수 있습니다


🐛 2. 대괄호로 시작하는 이름이 코드로 저장되던 문제
프로젝트 칸에 "[5.6] 판매조회" 처럼 대괄호로 시작하는 값을 넣으면, 대괄호 안의 "5.6" 만 프로젝트 코드로 저장됐습니다.
이제 입력한 값이 그대로 저장됩니다.

- 고친 곳: 새 업무 기록 (수동), 업무 기록 수정 창, 최근 업무 기록의 프로젝트 칸, 작업 프리셋 추가·수정 창
- 작업 프리셋의 프로젝트 드롭다운도 "[코드] 이름" 한 줄 대신 코드 / 이름 두 줄로 보입니다

(※ 이미 잘못 저장된 기록은 자동으로 고쳐지지 않습니다. 해당 기록의 프로젝트 칸을 다시 골라 주세요.)
