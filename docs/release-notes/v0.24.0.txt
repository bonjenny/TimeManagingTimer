v.0.24.0 - 시간관리를 ERP에 바로 등록할 수 있습니다!

이번 업데이트에서는 시간관리 탭에 정리한 내역을 ERP 시간 로그 게시판에 한 번에 등록하는 기능이 추가되었습니다.
ERP 그리드에 한 줄씩 옮겨 적던 작업을 버튼 하나로 끝낼 수 있습니다.


📤 1. 시간관리 등록 기능
시간관리 탭 상단에 [시간관리 등록] 버튼이 추가되었습니다.
누르면 ERP에 들어갈 모습(작업 / 업무 / 거래 / 카테고리 / 시간 / 비고)을 미리 보여주고, 합계 시간도 함께 확인할 수 있습니다.

👉 [사용 방법] ERP에 로그인한 탭의 주소창 URL을 복사
   ➡️ 시간관리 탭에서 날짜 선택 후 [시간관리 등록] 클릭
   ➡️ "ERP 세션" 칸에 복사한 주소를 붙여넣기
   ➡️ 미리보기 표와 합계를 확인하고 [ERP에 저장] 클릭
   ➡️ 확인창에서 승인하면 저장 완료! 새로 만들어진 시간 로그 번호가 표시됩니다.

(※ 붙여넣은 세션 정보는 브라우저 탭을 닫으면 사라지며, 백업 파일에는 저장되지 않습니다.)
(※ "세션 만료" 안내가 뜨면 ERP에 다시 로그인한 뒤 새 주소를 붙여넣어 주세요.)
(※ 작업·개발 게시글이 연결되지 않은 프로젝트가 있으면 상단에 빨간 안내가 뜨고 저장할 수 없습니다. [게시글 매핑 찾기]에 프로젝트 코드나 작업 게시글 번호를 넣고 [찾기] → [매핑 추가]를 누르면 연결됩니다.)
(※ 네트워크 오류로 저장이 안 되면 [콘솔 스크립트 복사]로 ERP 탭에서 직접 저장할 수 있습니다.)


🎨 2. 엑셀 Export 버튼 모양 변경
[엑셀 Export] 버튼이 초록색 강조 버튼에서 테두리 버튼으로 바뀌고, 아이콘도 내보내기(업로드) 모양으로 변경되었습니다.
