# 12. 가이드 (Guide)

## 개요

앱 안에서 각 화면의 기능과 사용 방법을 볼 수 있는 가이드 탭입니다. 화면별로 실제 화면을 흉내 낸 **HTML + CSS 애니메이션 예시**가 반복 재생되어, 드래그·우클릭·입력 순서를 글보다 쉽게 따라 할 수 있습니다. (v1.0.3)

## 화면 구성

- **상단 탭**: 「설정」 오른쪽 「가이드」(책 아이콘)
- **왼쪽 목차**: 시작하기 / 일간 타이머 / 주간 일정 / 배포 캘린더 / 프로젝트 분석 / 시간관리 / ERP 시간관리 등록 / 설정 / Q&A 게시판 / 키보드 단축키
- **본문** (위에서 아래 순서)
  1. 제목과 한 줄 요약
  2. 예시 화면 (애니메이션)
  3. 주요 기능 표: 기능 · 사용 방법 · 도입 버전
  4. 키보드 단축키 표 (키보드 단축키 섹션만)
  5. 알아두세요: 주의사항과 팁

## 예시 화면 목록

| 섹션 | 예시 | 보여주는 동작 |
|---|---|---|
| 시작하기 | 하루 업무 흐름 | 일간 타이머 → 기록 다듬기 → 시간관리 → ERP 저장 단계가 차례로 강조 |
| 일간 타이머 | 입력줄에 작업명을 쓰고 Enter로 시작 | 작업명 입력 → Enter → 진행 중 카드 등장, 타이머 증가 |
| 일간 타이머 | 예약 모드로 앞으로 할 업무 등록 | 시계 아이콘 → 예약 시간 줄 → 작업명 입력 → 예약 등록 → 점선 예약 막대 → 현재 시각 도달 시 자동 시작 |
| 일간 타이머 | 타임라인을 우클릭 드래그해 예약 등록 | 우클릭 드래그(주황 점선) → 「예약 일정 등록」 → 예약 막대 |
| 일간 타이머 | 타임라인 빈칸을 드래그해 지난 업무 기록 | 드래그 → 「새 업무 기록 (수동)」 → 저장 → 막대 생성 |
| 일간 타이머 | 막대 끝을 끌어 시간 조절 | 오른쪽 끝 드래그 → 자동 맞춤 기준선 → 시간 표시 갱신 |
| 일간 타이머 | 막대를 우클릭해 수정 · 삭제 | 우클릭 메뉴 → 「수정」 → 「업무 기록 수정」 저장 / 「삭제」 → 휴지통 알림 |
| 주간 일정 | 복사 형식을 고르고 복사 | 간단형 → 라벨형 전환 → 「복사」 → 복사 알림 |
| 배포 캘린더 | 일정 칩을 드래그해 날짜 이동 | 칩을 다른 날짜로 드래그 → 이동 알림 |
| 프로젝트 분석 | 카테고리를 펼쳐 작업별 시간 보기 | 비율 막대 → 카테고리 클릭 → 작업 행 펼침 |
| 프로젝트 분석 | 인터럽트 분석 | 키워드 추가 → 요약·히트맵·시간대 분포·이력 → 키워드 추가 시 재계산 → 최다 발생 주·피크 시간대 강조 |
| 시간관리 | 머리글을 차례로 눌러 다중 정렬 | 「작업」 → 「시간(분)」 클릭 → 행 재정렬, 순위 숫자 |
| ERP 시간관리 등록 | 세션 붙여넣기 → 게시글 매핑 찾기 → ERP에 저장 | 세션 입력 → 「찾기」 → 「매핑 추가」 → 「ERP에 저장」 → 확인 → 저장 완료 |
| 설정 | 백업 후 오래된 기록 정리 | 날짜 선택 → 삭제 대상 건수 → 「먼저 백업」 → 「삭제」 → 저장 용량 감소 |
| Q&A 게시판 | 건의사항 글쓰기 | 「글쓰기」 → 제목·비밀번호 입력 → 「등록하기」 → 목록 맨 위에 새 글 |
| 키보드 단축키 | Alt + 숫자로 탭 이동 | Alt+1~5 누름에 따라 탭 밑줄 이동 |

## 동작 규칙

- 예시는 끝나면 처음부터 다시 재생됩니다.
- 예시 위에 마우스를 올리면 그 장면에서 멈추고, 마우스를 떼면 이어서 재생됩니다.
- 운영체제의 "움직임 줄이기" 설정이 켜져 있으면 애니메이션 없이 핵심 장면에서 멈춘 화면을 보여줍니다.
- 예시의 숫자·이름은 설명용 예시 값이며 실제 데이터를 읽지 않습니다.
- 라이트/다크 모드와 테마 팔레트 색을 따라갑니다.

## 기타 변경

- 상단 탭이 7개가 되어 좁은 화면에서는 탭 줄이 가로로 스크롤됩니다. (다크 모드 버튼과 겹치지 않음)

## 구현 메모

- 외부 라이브러리 없이 MUI `Box` + emotion `keyframes`로 구현했습니다. (초기 mermaid 흐름도 방식은 제거)
- 모든 예시는 한 반복 주기(초) 위에서 퍼센트 시점으로 커서 이동·클릭·창 등장을 맞춥니다.
