# 배포 캘린더 (v0.14.0~)

배포 캘린더 탭에서는 배포 일정을 월간 그리드로 관리하고, HTML 테이블로 복사해 웹에디터에 붙여넣을 수 있습니다.

## 1. 접근 방법

- **탭**: 상단 메뉴에서 "배포 캘린더" 클릭
- **단축키**: `Alt + 3`

## 2. 화면 구성

- **보기 방식 (v1.0.9)**: 상단 날짜 옆 「주 | 월」 토글. 고른 값은 저장되어 다음에 열어도 유지된다. 모바일은 ⋮ 메뉴의 「월 단위로 보기 / 주 단위로 보기」. **설정 > 배포 캘린더 > 보기 방식**에서도 같은 값을 고를 수 있다.
  - **주 단위**: 오늘 기준으로 선택한 **주 수**만큼 표시 (월~금). 1주: 이번 주 / 2주(기본): 저번 주~이번 주 / 3주: 저번 주~다음 주 / 4주: 저저번 주~다음 주 (이번 주 앞에 `floor(주 수 / 2)` 주). 화살표는 한 주씩 이동. 제목 예) "2026년 2월 1주차 ~ 2주차", 1주만 볼 때는 "2026년 2월 1주차"
    - 주차 = 그 주 금요일이 그 달 몇 번째 금요일인지 (`getWeekOfMonth`). 예) 8/24 주 8월 4주차, 8/31 주 9월 1주차, 9/14 주 9월 3주차
  - **월 단위**: 한 달을 고정 표시 (9월이면 9월 전체). 화살표는 한 달씩 이동, 제목 예) "2026년 9월"
    - 그 달 **평일(월~금)이 하루라도 든 주**를 모두 보여준다. 예) 9월 달력에 9/28~9/30 주 포함. 1일이 토·일이면 그 주는 평일이 전부 전달이라 뺀다
    - 평일만 보므로 어떤 달도 **최대 5주**
    - 첫 주·마지막 주에 섞인 앞뒤 달 날짜는 흐리게 표시
  - 달력 아이콘: 주 단위는 이번 주, 월 단위는 이번 달로 이동
- **표시 주 수 설정**: **설정 > 배포 캘린더**에서 1주 / 2주 / 3주 / 4주 중 선택 가능 (주 단위 보기에만 적용). 자동 저장.
- **오늘 날짜 강조 (v1.0.9)**: 오늘 칸 머리에 「오늘」 배지·브랜드색 막대, 칸에 옅은 색. **설정 > 배포 캘린더 > 오늘 날짜 강조** 스위치로 끄고 켠다 (기본 켜짐). 화면 캡처로 공유할 때 끄면 된다.
  - HTML 복사에는 켜져 있어도 넣지 않는다 — 붙여넣은 문서는 날짜가 지나도 남기 때문
- **공휴일 표시 (v1.0.9)**: 날짜 머리에 공휴일 이름을 빨간 글씨로 표시(모바일은 칸 안). 날짜 글자도 빨간색. HTML 복사에도 휴일 줄로 들어간다. 같은 날 같은 이름의 휴일 이벤트를 직접 넣었으면 한 번만 보인다.
  - 데이터: `src/constants/krHolidays.ts` (2025~2027 하드코딩, 연말에 다음 해 추가 필요)
- 구현: `src/utils/calendar_export.ts` 의 `getMonthWeekMondays`, 상태는 `useDeployCalendarStore` 의 `view_mode` / `show_today`

## 3. 이벤트 관리

- **추가**: 빈 셀 클릭 → 날짜, 프로젝트 코드(자동완성), 표시명, 진행상태, 휴일 여부 입력
- **수정/삭제**: 이벤트 셀 클릭 → 모달에서 수정 또는 삭제. 모달에서 **Enter** 키로 저장 가능. 모달에서 잡 색상(기본·테마·직접 선택) 편집 가능.
- **우클릭 삭제**: 이벤트 칩에서 우클릭 → 컨텍스트 메뉴에서 "삭제" 선택 시 해당 이벤트만 삭제
- **드래그앤드롭**: 이벤트 칩을 다른 날짜 셀로 드래그하여 일자 이동
- **휴일**: 휴일 체크 시 해당 셀에 빨간색 텍스트로 표시 (예: 신정, 연차)

## 4. 잡 색상 설정

- **잡 색상 설정** 버튼으로 다이얼로그 열기
- 잡(프로젝트 코드)별로 배경색 지정
- **기본 색상**: 8색 파스텔 구역 + **테마 색상**: 설정 > 컬러 팔레트 테마 (다크모드 시 자동 보정)
- 컬러피커로 직접 선택 가능

## 5. HTML 복사 (v0.14.2~)

- **HTML 복사** 버튼 클릭 시 현재 화면에 보이는 범위(주 단위면 설정한 주 수, 월 단위면 그 달 4~5주)를 HTML 테이블로 클립보드에 복사
- 복사되는 내용은 **table 요소 및 하위 요소만** (최상위 wrapper div 제외)
- ecount 웹에디터, Notion, Excel 등에 붙여넣기 시 아래 스타일이 유지됨

### 내보내기 스타일

- **전체**: 얇은 회색 테두리, 둥근 모서리(8px), 고정 너비(835px), colgroup으로 열 너비 유지
- **날짜 헤더**: 옅은 회색 배경(#f3f4f6), 가운데 정렬, 고정 높이(36px), 상하 패딩
- **바디 셀**: 흰 배경, 최소 높이 72px, 칸·라벨 좌우 패딩
- **작업 라벨**: 잡별 배경색(td bgcolor + 인라인 스타일), 둥근 모서리(6px), 패딩(8px 12px 10px 12px), 라벨 간 margin(6px), 긴 텍스트 말줄임표
- **휴일**: 빨간색(#ca3626) 텍스트, 가운데 정렬

## 6. 데이터

- 모든 데이터는 **LocalStorage**에 저장 (`timekeeper-deploy-calendar`)
- 프로젝트 코드는 기존 **설정 > 프로젝트** 및 일간 타이머에서 사용한 코드가 자동완성에 표시됨
