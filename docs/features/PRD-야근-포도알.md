# PRD: 야근 포도알 스티커판

| 항목 | 내용 |
| --- | --- |
| 상태 | 초안 (2026-11-12) |
| 대상 | TimeKeeper 웹앱 + 캘린더 바탕화면 위젯 |
| 한 줄 요약 | 야근한 날마다 포도알이 한 알씩 채워지고, 한 송이를 다 채우면 기념 카드가 나온다 |

## 1. 왜 만드나

- 야근은 기록은 남는데 돌아볼 일이 없다. 타이머에 18시 이후 기록이 쌓여도 "이번 달 몇 번 늦게 갔지?"는 아무도 세지 않는다.
- 어릴 때 칭찬 스티커판처럼 한 알씩 채우는 재미를 붙이면, 야근을 **자랑이 아니라 자조 섞인 기념**으로 돌아보게 된다. 동료에게 공유하기 좋은 소재다 (참고한 릴스도 "야근하는 친구한테 공유"가 핵심).
- TimeKeeper에는 이미 판정 재료(타이머 세션의 끝난 시각, 근태)가 있어서 **사용자가 따로 입력하지 않아도** 채워진다. 이게 다른 스티커판 앱과의 차이다.

### 하지 않을 것 (Non-goals)

- 야근을 장려하는 장치. 팀 랭킹 · 많이 한 사람 순위는 만들지 않는다.
- ERP 근태 신청 · 연장근무 결재 연동 (읽기만 하고 쓰지 않는다).
- 서버 저장 · 계정. 지금 앱처럼 내 브라우저(IndexedDB)에만 둔다.

## 2. 결론부터: 웹앱에 먼저, 위젯은 보기 전용으로

| | 웹앱 안 기능 | 바탕화면 위젯 |
| --- | --- | --- |
| 판정 데이터 | 타이머 기록 · 근태를 바로 읽음 | 못 읽음. 앱이 백업 폴더에 써 주는 스냅숏만 봄 (1.5초 늦게, 한 방향) |
| 포도알 붙이기 · 취소 | 바로 저장 | 위젯 → 앱으로 보낼 길이 없음 (새로 만들어야 함) |
| 늘 눈에 보이기 | 탭을 열어야 보임 | 바탕화면에 늘 보임 (릴스의 작은 창 느낌) |
| 설치 | 없음 | exe 따로 받아야 함 |

판정 · 저장은 앱에 있어야 하고, "늘 보이는 작은 판"은 위젯이 잘한다. 그래서 **1단계는 웹앱**, **2단계에서 위젯에 판 보기를 얹는다**. 위젯은 지금 캘린더처럼 스냅숏을 받아 그리기만 한다. 붙이기는 자동 판정이 대부분이라 위젯에서 못 눌러도 크게 아쉽지 않다.

## 3. 사용자와 상황

- **나 (개발자 · 기획자)**: 타이머를 켜 두고 일한다. 늦게까지 남은 날 퇴근하면서 포도알이 하나 늘어난 걸 본다.
- **동료**: 내가 공유한 기념 카드를 메신저에서 받아 웃는다. TimeKeeper를 안 써도 카드는 이미지라 그냥 보인다.

## 4. 기능 요구사항

### 4.1 야근 판정 (P0)

- **야근 1회** = 그날 타이머 세션 중 하나라도 **퇴근 기준 시각 + 여유 시간**을 넘겨 끝난 날.
  - 퇴근 기준 시각: 설정값, 기본 18:00
  - 여유 시간: 설정값, 기본 30분 (18:10 퇴근까지 포도알 주면 의미가 없다)
  - 자정을 넘긴 세션은 시작한 날로 친다 (지금 일간 타이머가 날을 나누는 방식과 같게)
- 하루에 **최대 1알**. 두 번 늦게 남아도 1알.
- 주말 · 공휴일에 기록이 있으면 **특근**으로 1알, 색을 다르게 (공휴일은 캘린더에 이미 있는 공휴일 목록을 쓴다).
- 타이머를 안 켜고 야근한 날을 위해 **수동 붙이기**를 둔다: 날짜를 골라 붙이고, 메모 한 줄 (선택).
- 자동으로 붙은 알도 **떼기**가 된다 (판정이 틀렸을 때). 뗀 날은 다시 자동으로 붙지 않는다.
- 판정은 앱을 열 때, 그리고 타이머를 멈출 때 다시 한다. 지난 기록을 고쳐도 반영된다.

### 4.2 스티커판 (P0)

- 한 판 = **20알** (설정: 10 / 20 / 30).
- 포도송이 모양 판에 붙은 순서대로 채운다. 알마다 날짜가 있고, 누르면 그날 기록 요약이 나온다:
  - 퇴근 시각
  - 야근 시간
  - 그날 가장 오래 한 작업
- 판 아래쪽에 **"19 / 20알 · 1알 남았어요"** 진행 막대.
- 판 이름은 사용자가 고친다 (기본: "야근 포도알 1송이").
- 화면 위치: 일간 타이머 오른쪽 작은 카드, 또는 메뉴 하나 추가. **결정 필요 (7장 질문 1)**.

### 4.3 한 송이 완성 (P0)

- 마지막 알이 붙는 순간 축하 연출 1회: 송이가 반짝이고, 종이 꽃가루가 1.5초 동안 떨어진다. 움직임 줄이기 설정이면 생략.
- **기념 카드**를 띄운다. 카드에 들어갈 것:
  - 판 번호와 기간 (예: 3번째 송이 · 9/1 ~ 11/12)
  - 야근 횟수 · 총 야근 시간 · 가장 늦은 퇴근 (예: 23:41, 10/23)
  - 가장 많이 늦게까지 붙잡은 작업 Top 3 (끄기 가능, 7장 질문 3)
  - 한 줄 문구 (무작위, 예: "축하합니다! 포도 한 송이를 회사에서 완성하셨습니다", "이제 퇴근 좀")
- 버튼: **PNG 저장**, **이미지 복사** (메신저에 바로 붙여넣기). 브라우저가 복사를 못 하면 저장만.
- 닫으면 다음 판이 빈 송이로 시작된다. 완성한 판은 **지난 송이**에 남는다.

### 4.4 지난 송이 (P1)

- 완성한 판 목록: 판 번호, 기간, 야근 횟수, 총 시간. 누르면 그 판과 기념 카드를 다시 본다 (다시 저장 · 복사 가능).

### 4.5 설정 (P1)

- 퇴근 기준 시각, 여유 시간, 한 판 알 수, 주말 · 공휴일 특근 포함 여부, 기념 카드에 작업명 넣기.
- 기능 끄기 (끄면 판 · 판정 모두 숨김, 데이터는 남김).

### 4.6 위젯에 판 보기 (P2)

- 위젯 스냅숏(`timekeeper-calendar-widget.json`)에 `grape` 묶음을 추가한다:
  - 현재 판 이름
  - 알 목록 (날짜 · 특근 여부)
  - 목표 알 수
  - 마지막 완성 정보
- 위젯 위쪽 줄에 「캘린더 / 포도알」 전환 버튼. 포도알 화면은 송이와 진행 막대만, 누르면 앱을 연다.
- 위젯에서 붙이기 · 떼기는 하지 않는다 (2장 이유).

### 4.7 테마 꾸미기 (P2)

- 테마별 알 모양:
  - 기본은 포도
  - 바다는 진주
  - 할로윈은 사탕 (재미 요소, 필수 아님)

## 5. 데이터

새 저장소 `useGrapeStore` (IndexedDB, 지금 스토어들과 같은 방식, 백업 JSON에 포함):

```ts
type Grape = {
  date: string;            // YYYY-MM-DD, 판 안에서 유일
  kind: 'overtime' | 'holiday';
  source: 'auto' | 'manual';
  ended_at?: string;       // 그날 가장 늦게 끝난 세션 (자동일 때)
  overtime_minutes?: number;
  memo?: string;
};
type GrapeBoard = { id: string; name: string; goal: number; grapes: Grape[]; started_at: string; completed_at?: string };
type GrapeState = {
  boards: GrapeBoard[];        // 마지막이 진행 중인 판
  removed_dates: string[];     // 사용자가 뗀 날 (자동 판정이 다시 붙이지 않게)
  settings: { end_time: string; grace_minutes: number; goal: number; include_holiday: boolean; show_tasks_on_card: boolean; enabled: boolean };
};
```

- 판정 함수는 순수 함수로 둔다: `judgeOvertime(logs, settings, holidays) => Grape[]`. 테스트하기 쉽게.
- 이미 판에 있는 날 · 뗀 날은 건너뛴다. 판이 다 차면 넘친 알은 다음 판으로.

## 6. 화면 · 톤

- 그림은 직접 그린 SVG. 포도송이는 알 20개 자리가 정해진 모양, 빈 자리는 점선 동그라미.
- 문구는 위트 있게, 그러나 **야근을 칭찬하지 않는다**. "고생했어요"보다 "오늘은 일찍 가요" 쪽.
- 기념 카드는 세로 4:5 (메신저 미리보기에서 잘리지 않는 비율), 어두운 · 밝은 테마 모두 같은 카드 (공유용이라 고정).
- 참고 릴스의 디자인(레트로 인쇄 포스터 풍)은 분위기만 참고하고 그대로 따라 그리지 않는다.

## 7. 정할 것 (질문)

1. 판을 어디에 둘까? (a) 일간 타이머 오른쪽 작은 카드, (b) 새 메뉴 「포도알」, (c) 캘린더 페이지 안. **추천: (a)**. 매일 보는 화면이라 붙는 순간을 본다.
2. 근태(ERP)도 판정에 쓸까? 연장근무 근태가 있으면 타이머가 없어도 1알. 근태 조회는 지금 세션이 있어야 해서 1단계에선 **타이머만** 추천.
3. 기념 카드에 작업명을 기본으로 넣을까? 공유하면 회사 업무명이 밖으로 나간다. **추천: 기본 끔**, 켜면 넣기.
4. 여유 시간 기본 30분이 맞나? 팀 퇴근 문화에 맞춰 정한다.

## 8. 단계와 범위

| 단계 | 범위 | 끝났다는 기준 |
| --- | --- | --- |
| P0 | 판정 · 판 · 수동 붙이기/떼기 · 완성 연출 · 기념 카드 PNG 저장 | 지난 한 달 타이머 기록으로 판이 맞게 채워진다 (판정 함수 테스트 통과) |
| P1 | 이미지 복사 · 지난 송이 · 설정 | 카드를 메신저에 붙여넣으면 바로 보인다 |
| P2 | 위젯 판 보기 · 테마 꾸미기 | 위젯에서 진행 막대가 앱과 같은 숫자 |

## 9. 위험

- **야근 미화로 읽힘**: 문구 · 랭킹 없음 · 끄기 옵션으로 줄인다.
- **판정 오류** (타이머 끄는 걸 잊고 퇴근): 떼기 + "끝난 시각이 비정상적으로 늦으면(예: 다음날 3시 넘음) 자동으로 붙이지 않고 물어보기".
- **공유 이미지에 회사 정보**: 작업명 기본 끔 (7장 질문 3).
